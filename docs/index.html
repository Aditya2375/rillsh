02 / THE NATIVE EXECUTION MODEL

Start together.
Close carefully.
Wait for everyone.

01

Real concurrency

The CLI starts every pipeline stage before waiting. A producer can fill more than one pipe buffer without waiting for a consumer that has not started.

02

Only the ends you need

Children receive their stdin and stdout connections, then apply ordered redirections. Unused descriptors close so readers can see EOF and early consumers can trigger SIGPIPE.

03

One status, deliberate state

All children are reaped. The last stage sets the pipeline status. Single builtins can change the shell; pipeline builtins run in children and cannot change the parent.

03 / KNOW THE EDGES

A shell, with a stated scope.

Full language contract ↗

What it speaks

Single and double quotes, escapes, $NAME, ${NAME}, $? and $$. Concurrent pipelines, ; and newline lists, left-associative && / ||. Ordered <, >, >>, <& and >& on descriptors 0, 1 and 2.

Builtins: cd, pwd, export, unset, exit, true and false. Interactive prompt, -c execution, bounded stdin scripts and side-effect-free --plan.

What it leaves out

Not POSIX sh. No field splitting, globbing, command or arithmetic substitution, assignment prefixes, control structures, aliases, rc files, history, completion, background jobs or job control. Ctrl-Z is ignored; Ctrl-C interrupts foreground commands.

One word stays one argument, even an unset variable. Source is ASCII. This is not a login shell or a replacement for /bin/sh.

What you must trust

The native shell can run arbitrary commands and truncate files with your account's permissions. It is not a sandbox. Use trusted commands, paths and environment values. Root and set-ID invocation are refused.

Linux 5.3+ with /proc and Python 3.10+, single-threaded CLI. No timeout or output cap on native commands. Browser plans are bounded and local; they are not proof a command will succeed.

Bounds: 8,192 source characters · 1,024 tokens · 32 pipelines · 16 stages per pipeline · 128 words and 16 redirections per stage · 65,536 UTF-8 bytes per expanded word.
